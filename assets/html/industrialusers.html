Industrial Users at LS-CAT

LS-CAT provides beamtime to industrial users through two separate programs:

  1. The APS General User Program
  2. LS-CAT directly as an Associate Member.

Note that LS-CAT provides data analysis software licensed for academic use. Beamtime includes data collection and retrieval services, but data analysis (e.g. indexing and structure determination) require the use of third-party software that is only free for academic and non-profit users. Commercial use of this software is possible only if covered by your own license agreement. Please refer to the LS-CAT Terms of Service for details.
