Steps to fill out a No X-ray ESAF

  1. Create No X-ray ESAF
  2. General tab: Fill-in Experiment Title that denotes synchrotron and proposed data collection date
  3. Click SAVE to populate the tabs
  4. Description tab: note Location for work, Start & End Dates, Description text with modification to expression source
  5. Experimenters tab: add all relevate users and set User Type to Remote
  6. Materials tab: use relevant acronym names
  7. Lab Use tab: Click Submit ESAF button
