Universal Puck (Uni-Puck) Sample Mounting System

The Universal V1-Puck (Unipuck) is a sample pin storage and shipping container for use with automated sample mounting systems worldwide—including ALS, Diamond, ESRF, NSLS-II, SLS, and SSRL.

Compatible with the CX100 and CXR100 dry shippers. For groups just starting, we recommend purchasing a starter kit with customized ID-numbering and a 2D barcode.
