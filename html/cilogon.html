Access to LS-CAT's remote interface requires the use of a CILogon account.

If you do not a CILogon account, please create an account using your institution as the identity provider and submit your account's associated email address to support@ls-cat.org .

Warning: CILogon and Globus offer the ability to create accounts using alternative identity providers, such as ORCID and Google. Support for data collection on LS-CAT's remote access and LS-CAT data retrieval via Globus using alternative identity providers is not guaranteed.
